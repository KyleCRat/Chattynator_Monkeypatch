# Changelog

## Unreleased

### Added

- Added a right-side scrollbar to Copy Messages, with a draggable thumb, arrow buttons, and track paging connected to the existing chat-copy scrolling.
- Copy Chat can be dragged by its title bar without blocking the close button, with its position remembered across reopening and reloads.

### Changed

- Increased Copy Messages from 200 to up to 1,000 available messages, including development output, while preserving Chattynator's filters and formatting. The copy box updates once per request; history retention and dump storage are unchanged.

## 12.1.0-1

- Added EllesmereUI Unlock Mode registration for detected Chattynator windows.
- Added persistent movement and resizing with combat-safe deferred application.
- Added solid RGB color and opacity controls.
- Added two-stop RGBA gradients with vertical and horizontal directions.
- Added native Blizzard Settings integration, hex color entry, slash commands, and manual rescanning.
