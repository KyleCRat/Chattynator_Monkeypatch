# Changelog

## [12.1.5-1] - 2026-10-06

- Updated for WoW 12.1.5.

- Added EllesmereUI Unlock Mode movement and resizing for Chattynator windows.
- Added configurable solid and gradient chat backgrounds.
- Expanded Copy Messages to up to 1,000 available messages, with a scrollbar
  and a draggable copy window that remembers its position.
- Added Blizzard settings and `/cmp` commands for configuration and rescanning.
